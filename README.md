# ☀️ 모닝 증시 큐레이터 (Morning Stock Radar)

전업투자자를 위한 **장전 증시 뉴스 통합 수집 및 네이버 카페 원클릭 칼럼 발행기**입니다.

---

## 📌 주요 기능

1. **글로벌 마감 지수 & 매크로 실시간 연동**
   - 다우, 나스닥, S&P500, 필라델피아 반도체(SOX)
   - 원·달러 환율, WTI 유가, 미 국채 10년물 금리
   - 당일 등락률 및 수치 자동 계산

2. **전일 밤~장전 실시간 증시 뉴스 스트림**
   - 네이버 뉴스 증권 속보, 산업/기업, 글로벌 경제
   - 구글 뉴스 RSS (미국증시 마감 및 월가 속보, 장전 공시/특징주)
   - 150+개 이상의 기사를 실시간 시간순 정렬
   - 자동 테마 태깅: `[반도체/AI]`, `[2차전지]`, `[바이오]`, `[원전/전력]`, `[방산]`, `[공시/특징주]` 등
   - 시간대별 필터: `장전 아침(06시~)`, `새벽 속보(00~06시)`, `최근 2시간`

3. **투자자 전용 큐레이션 데스크 (오른쪽 패널)**
   - 기사 옆 `[+ 픽(담기)]` 버튼으로 중요 뉴스 선별
   - 순서 변경 및 삭제
   - **"💡 내 코멘트"**: 기사별로 나만의 투자 관점/관련 종목 바로 입력
   - 직접 뉴스나 주요 이슈 추가 기능 (`[직접 추가]`)

4. **네이버 카페 원클릭 발행**
   - **`[✨ 네이버 카페 서식으로 복사]`** 원클릭
   - 네이버 카페 글쓰기(스마트에디터 ONE) 창에서 `Ctrl + V` 누르면:
     - 깔끔한 제목 박스
     - 지수 비교 표
     - 테마별 분류 및 뉴스 목록
     - 💡 하이라이트된 투자자 코멘트
     - 원문 링크
     - 깔끔한 마감 인사말
   - 일반 텍스트 복사(텔레그램/카카오톡용) 및 미리보기 지원

---

## 🚀 실행 방법

바탕화면에 있는 **[모닝 증시 큐레이터]** 아이콘을 더블 클릭하시면 웹 브라우저가 자동으로 열립니다!
